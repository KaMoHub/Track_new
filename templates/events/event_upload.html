Поддерживаются форматы Excel: .xlsx и .xls
Инструкция по загрузке
  • Файл должен быть в формате Excel (.xlsx или .xls)
  • Первая строка должна содержать заголовки колонок
  • Данные начинаются со второй строки
  • Обязательные поля: name (Название конкурса) и level (Уровень)
  • Если description (Описание) не указано, будет скопировано из названия
  • Поля application_deadline (Срок подачи заявки) и result_date (Дата результатов) не обязательны
Отмена
Пример структуры Excel файла
name description level application_deadline result_date
НПК ШАГ в будущее Научно-практическая конференция Городской 15.03.2024 30.04.2024
Конкурс юных талантов Международный конкурс талантов Международный 10.02.2024 25.03.2024
Важно
  • Даты указываются в формате ДД.ММ.ГГГГ
  • Уровни: Центровский, Городской, Районный, Республиканский, Региональный, Межрегиональный, Всероссийский, Международный
  • Существующие конкурсы будут обновлены
  • Новые конкурсы будут созданы
