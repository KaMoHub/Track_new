Инструкция по загрузке
  • Файл должен быть в формате Excel (.xlsx или .xls)
  • Первая строка должна содержать заголовки колонок
  • Данные начинаются со второй строки
  • Обязательные поля: Название конкурса и Уровень
  • Название конкурса формируется как: "Номер + Название мероприятия"
  • Даты указываются в формате ДД.ММ.ГГГГ
  • Уровни: Центровский, Городской, Районный, Республиканский, Региональный, Межрегиональный, Всероссийский, Международный
  • Направление: Наука, Спорт, Образование, Творчество
  • Формат: Очная, Очно-дистанционная, Заочная
  • Приоритет: числовое значение (меньше = выше в списке)
  • При выборе режима "Обновление существующих" в Excel обязательна колонка с ID конкурса
  • При режиме "Только добавление" дубли по названию будут пропущены
  • Перед загрузкой будет показан лог изменений для подтверждения
