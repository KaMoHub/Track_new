1. Обновление проекта

# проверяем наличие изменений
git status

# забираем изменения из гит
git pull origin main

#если были изменения в структуре
python manage.py migrate




2. настройка нового проекта

Лучше сначала локально настраиваем - добавляем пользователей и т.п. Получаем файл db.sqlite3 и его вручную загрузить в корень проекта на сервере.

2.1. Клонируем репозиторий
    git clone https://github.com/username/your-repo.git

2.2. Устанавливаем зависимости
    pip install -r requirements.txt

2.3. Запускаем команду migrate
    python manage.py migrate

2.4. Запускаем команду createsuperuser
    python manage.py createsuperuser

2.5. Запускаем команду runserver
    python manage.py runserver
    superuser-ом заходим в админку. Там создаем пользователей и преподователей, студии и направления

2.6. Проверяем, что все работает и загружаем данные в базу


3. Делаем деплой на сервере, вручную загружаем файл db.sqlite3 в корень проекта  и файлы settings.py, wsgi.py в папку track из папки server
